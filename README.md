中国数据图谱 · China Stats Atlas：把国家统计做成一本可以逛的数据年鉴。总览页有 2024 年关键指标大数字动画与年度焦点故事；省份图谱用 31 省瓷砖地图支持点选详情、双省对比与可排序表格；趋势长河用年份滑杆和播放动画回看 2005—2024 年的 GDP、人口与城镇化；经济、人口、民生三个专题各有手绘 Canvas 图表与编辑式解读；数据说明页交代来源与口径。全部数据取自国家统计局公开统计的真实量级并手工嵌入本地文件，静态站点零网络请求，桌面与手机都能用。
